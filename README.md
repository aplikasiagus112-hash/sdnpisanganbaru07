# Vercel Wrapper - SDN Pisangan Baru 07

Folder ini adalah wrapper iframe statis untuk deployment Google Apps Script baru.

## Upload manual ke GitHub

Upload isi folder ini ke root repository:

`https://github.com/aplikasiagus112-hash/sdnpisanganbaru07.git`

Struktur root repository yang disarankan:

```text
index.html
vercel.json
README.md
```

Jika folder `vercel` diunggah sebagai subfolder repository, atur **Root Directory** project Vercel menjadi `vercel`.

Tidak diperlukan perintah build, package manager, atau environment variable.

Target iframe:

`https://script.google.com/macros/s/AKfycbxA6oDmjD6LX4f3IeuGJ7yT-Yt-6DrlI8WK3Yr7IqS6u4o2JW5-MqOh-l_oTQoBceOOOQ/exec`
